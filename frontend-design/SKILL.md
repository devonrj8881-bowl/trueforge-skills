# Frontend Design

1. Inspect the existing framework, components, styles, and design language.
2. Preserve working behavior and established patterns unless change is requested.
3. Define hierarchy, spacing, typography, states, responsiveness, and accessibility before editing.
4. Prefer reusable components and existing tokens over one-off CSS.
5. Avoid decorative glow, gradients, or animation unless requested or already part of the product language.
6. Render or preview the result when tools allow.
7. Validate keyboard use, contrast, overflow, mobile layout, and loading/error/empty states.
